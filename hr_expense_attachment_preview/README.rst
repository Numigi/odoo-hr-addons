HR Expense Attachment Preview
=============================

This module allows previewing attachments linked to expense report lines. 
It enhances visibility by enabling users to preview receipts directly without downloading them. 

Once installed, users can see previews of attachments on expense report lines without having to open each file manually. 

.. image:: static/description/hr_expense_form.png

Dependencies
------------
The module integrates with `many2many_attachment_preview` from Cybrosys, 
which provides the attachment preview functionality in Odoo.
